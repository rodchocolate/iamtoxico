iamtoxico.com is an AI-driven print-on-demand streetwear brand integrated with Shopify and Printify. The brand utilizes a custom automated pipeline called Hermes to rapidly transition designs from email to live, purchasable products.

Overview

iamtoxico.com is a streetwear brand that operates via a Shopify storefront (`iamtoxico.myshopify.com`) and Printify for fulfillment. The technical infrastructure includes a Flask-based backend for development and a central `catalog.json` file that manages both live Printify products and affiliate items sourced from Amazon. The system maintains both a live production shop and a disconnected staging store for development.

Product line

The current live product offering consists exclusively of Harem Pants, including the following styles:

  • Arctic River
  • Cyan Glow
  • Frozen Sky
  • Hold Cards
  • Hot Oil
  • Toxico

Additional products in the staging phase include zip hoodies, cover/pullover hoodies, shorts, blankets, kimono robes, long sleeve tees, boxy tees, women's thongs, windbreakers, puffer jackets, comforters, and full-zip hoodies.

How it works

The brand employs the "Hermes" pipeline for "instant drops." This process allows a user to email a design image, which is then automatically converted into live products across a curated set of garments (such as apres/harem, hoop, and puffer) without an approval gate.

Because Printify mockup rendering and Shopify URL (handle) synchronization can be slow, the system uses a placeholder and backfill architecture:

1. Instant Drop: The `instant_drop.py` script saves the emailed design as a placeholder image so storefront tiles are not blank upon creation.

2. Parallel Publishing: Products are published in parallel to reduce the time required for a drop to land.

3. Backfill: A separate worker (`ingest/backfill_drops.py`) runs every 300 seconds to sweep the catalog and replace placeholders with real Printify mockups and live Shopify URLs once they are generated.

Evolution
